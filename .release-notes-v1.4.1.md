# Pal Lab v1.4.1

A save-aware Palworld breeding planner. Point it at your save and get a
concrete, do-this-next breeding plan from the pals you already own.

## What's new in 1.4.1

- **Surgery table + gender reverser in the solver.** Two new cost options let
  the solver relax the final breeding step: implant a missing required passive
  (Surgery table) or flip a parent's gender (gender reverser), each priced as an
  effort cost. Exact plans still win ties, and special lottery-tier passives
  (World-Tree, Rainbow) are correctly refused — no dead remedies.
- **Honest Mutations card.** What's actually known about breeding mutations:
  ~1% per egg (code-verified), and the outcome pools are *not* publicly decoded.
  No invented odds.
- **Save remembrance on the web.** The browser app now remembers your save
  across visits. Chromium gets a one-gesture folder reload; **every** browser —
  including Firefox, Safari, and Brave — gets a one-click **Restore** from a
  stored byte snapshot, with no prompt at all. Saves are still parsed entirely
  in your browser and never leave your device.
- **Chrome AppData workarounds.** Chromium refuses folders under `AppData`
  (exactly where Palworld saves live). A blocklisted drop now loads anyway, the
  dropzone offers a classic-dialog escape hatch, and the hint names the real
  save path (`AppData\Local\Pal\Saved\SaveGames`).

## First release since 1.0.0

This is the first build cut since 1.0.0, so desktop users upgrading jump
straight from **1.0.0 to 1.4.1** and pick up everything from the 1.1–1.4 line
along the way:

- **1.1** — no-path diagnostics ("here's *why* there's no plan"), solve
  persistence + history, bred-node hover cards, and an out-of-memory crash fix
  for heavy IV solves.
- **1.2** — saved-plan tracking (plans auto-check steps as you breed in-game),
  Pal-dex collection mode with a "Breed missing" queue, dex reachability, and
  the whole repo relicensed to **MIT**.
- **1.3** — Pal Lab on the web at [pal-lab.pages.dev](https://pal-lab.pages.dev)
  (same solver via wasm), client-side save loading, and single-source
  versioning.
- **1.4.0** — Pal-dex PARTNER tab (all 299 partner skills), passive
  multi-select filter parity on Palbox, and a condensation-rank off-by-one fix.

See [CHANGELOG.md](CHANGELOG.md) for the full per-release detail.

## Installing

Download the **installer** or **portable ZIP** below, launch Pal Lab, and point
it at your save (or let it auto-detect).

### SmartScreen note

Pal Lab is an unsigned community build, so Windows SmartScreen may warn on first
run. Click **More info → Run anyway**. A **VirusTotal** link is included so you
can verify the binary yourself before running it.

### Xbox / Game Pass saves

Xbox / Game Pass saves use the packed **CNK** format. Convert them with
[palworld-save-pal](https://github.com/oMaN-Rod/palworld-save-pal) first; Pal
Lab detects a CNK save and explains what to do.
