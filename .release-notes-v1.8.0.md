# Pal Lab 1.8.0

**Dedicated servers, live over SFTP.**

If you play on a dedicated server, the save-backup shuffle is over. Point the
desktop app at your server and Pal Lab reads the world directly over SSH:

- **Dedicated server (SFTP)** button on the load screen — host, user,
  password *or* key file, and the save path (or just the `SaveGames` parent —
  we scan for worlds).
- **Live updates:** Pal Lab polls the server every 60 seconds and silently
  refreshes your roster while you play — the same auto-reload local saves get.
- **Read-only, and paranoid about it:** nothing is ever written to your
  server. The host fingerprint is pinned on first connect — if it ever
  changes, Pal Lab refuses and shows you both fingerprints. Passwords are
  held in memory for the session only; they are never written to disk.
- Everything works on the live connection: Solver, IV Lab, Pal-dex, world
  settings. Reopening the app offers one-click reconnect.

## Advanced stations, tuned by actual play

- **Surgery table — implantable passives.** You can now list exactly which
  passives the solver is allowed to implant (leave it empty to allow any).
  If a plan is impossible because your list excludes the missing passive,
  the diagnosis says precisely that.
- **Station time costs now default to 30 seconds** (surgery, gender
  reverser, skill fruits) — matching what these actually take in-game —
  instead of the old cautious 300s. Still tunable if your runs differ.
