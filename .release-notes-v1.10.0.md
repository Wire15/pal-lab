# Pal Lab 1.10.0

Dedicated-server quality of life: stay connected, reconnect instantly.

## Added

- **Remembered SFTP logins.** Opt-in "Remember password" on the connect form
  keeps your password (or key passphrase) in the **OS credential vault**
  (Windows Credential Manager) — never a file, never plaintext. With it set,
  opening Pal Lab reconnects to your server and loads your world
  automatically, exactly like local saves. Untick the box and the stored
  secret is scrubbed.

## Fixed

- **Reconnecting after closing the app** no longer fails with
  "error opening ssh channel: disconnected". Pal Lab used to drop the
  connection without an SSH goodbye, so hosts that cap concurrent SFTP
  sessions kept the old one as a zombie and refused the new one. Now the app
  disconnects gracefully on close/switch/exit, retries once with a fresh dial
  when a host is slow to reap, sends SSH keepalives on long-lived sessions,
  and explains clearly if the host still holds an old session.

**Windows SmartScreen:** this is an unsigned build. If SmartScreen warns you,
click **More info -> Run anyway**.
