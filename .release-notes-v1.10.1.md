# Pal Lab 1.10.1

Small diagnostic upgrade for dedicated servers.

## Changed

- **SFTP errors now quote the server.** When a host closes the session, the
  error includes the server's own stated reason (e.g.
  `server said: "Too many logins"`) - naming the exact limit instead of a
  bare "disconnected".

**Windows SmartScreen:** this is an unsigned build. If SmartScreen warns you,
click **More info -> Run anyway**.
