# Pal Lab 1.5.0

**The headline: attack-skill inheritance solving — no other tool does this.**

## Breed for active skills

Add **Required moves** to any solver target. Pal Lab reads which of your pals
have the move **equipped** (that's the post-1.0 rule — inherited skills are
drawn from the parents' equipped slots, per the official 1.0 patch notes),
finds a carrier, and threads the move through the breeding path — `INHERIT`
chips mark where it passes, and the ~50%-per-egg inheritance roll
(community-measured, and labeled as such — never presented as exact) is priced
into every egg and time estimate.

The honest details, because that's how we do things:

- Per-move eligibility is datamined (`IgnoreRandomInherit`): species-exclusive
  moves are correctly refused, and the no-path panel tells you why.
- Moves your target learns by level-up are auto-satisfied — the plan says
  "no breeding needed" instead of wasting your time.
- Only **one** move can pass down per breeding line. Extra required moves can
  ride a **Skill Fruit** instead: toggle *Skill Fruits* under Advanced
  stations with your own time cost, and they appear as `FRUIT` steps.
- The Pal-dex now shows INHERIT / FRUIT flags on every active skill.

## Share plans as links

**Copy link** sits next to Copy code. Send it to a friend: opening it loads
the Solver and re-solves the plan **against their save** — their pals, their
odds, honestly recomputed. Codes ride the URL `#` fragment, so they never
appear in any server log.

## Install the web app

Pal Lab web is now a PWA: install it from the browser menu, get instant
repeat loads and an offline app shell. Same zero-install URL:
https://pal-lab.pages.dev
